# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it by emailing <aisberg@posteo.de>.

Please include:

- Description of the vulnerability
- Steps to reproduce
- Affected versions
- Suggested fix (if any)

I will acknowledge receipt within 48 hours and aim to respond with status updates regularly.

## Supported Versions

Only the latest release is supported for security fixes. Older versions are not backported.
